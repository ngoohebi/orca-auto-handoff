Hit a rate limit? Auto-switch to your next account.

OAH (Orca Auto Hand-off) pools your Orca-managed accounts per service and hands off sessions automatically when an account hits a limit or runs low while you are away. Claude resumes as the exact same session with your unsent text intact; Codex, Antigravity, OpenCode, and Devin continue from a structured summary.

How it works

Smart forecasting, zero babysitting

Out of the box OAH runs Auto · Early when away. While you are at Orca, sessions move only at a real limit; once you step away for 10 minutes, Claude sessions hand off shortly before running out so work never stalls mid-turn.

Claude exact resume

Selects the next healthy Claude account, safely closes the old pane, resumes the exact conversation (agent.resume), restores plain unsent text, and types Continue. after an interruption.

Codex, Antigravity, OpenCode, Devin summary

Hand off at real limits (or via Early hand off) into a fresh session with a ≤4,096-character summary: reason, branch, git status, git diff --stat, and last 40 lines.

3-State Circuit Breaker

Formal closed → open → half_open → closed tracking keeps healthy accounts ahead of recovering ones and prevents ping-ponging across nearly-empty accounts.

Nested-Window Pacing

Combines 2-sample burn-rate runway with whole-window projection (usedPercent / elapsedFraction) across 5h, weekly, and model windows, and spends expiring weekly quota first.

Per-Model Cap Policy

Choose how model weekly caps (like Claude Fable) behave: try /model fallback first, proactively rotate away and avoid 0% buckets, or ignore model-only limits.

Global Claude Status Line

One switch in Settings (on by default) shows live multi-account bars at the bottom of Claude Code across every workspace (~40 ms), keeping any existing status line above OAH's rows.

Direct Live Quota

Current usage for every saved account — even while you're away

Orca is the primary source of usage (read over Orca's local socket in ~1 ms). When Orca's reading for an inactive account is missing or stale (>15 min for Claude, >10 min for others), Live quota fills the gap directly using the sign-in Orca already saved — never touching your Keychain.

In Orca

A quiet 3-tab sidebar panel

Monochrome, hairline-divided, and fast — built to match Orca's own interface without visual noise.

Accounts

One-line service headers, compact account rows with status beside the name and right-aligned actions (Early hand off, End cooldown). Pressing Early hand off keeps automatic hand-off ON. Follows tab switches within ~1 s.

History

Every hand-off explained in plain words, grouped under day headings, with failed hand-offs highlighted in danger tone.

Settings

Six core choices up front (Pick, Timing, When all used, Session on screen, Live quota, Claude status line), grouped Advanced fine-tuning below, and Save/Undo for typed values.

Safety & Privacy

Fail-closed by default

Session Protection

  • Never interrupts a running turn: hands off only between turns, when idle, or at a limit.
  • On-screen care: ask (default), careful (presence-aware countdown), wait, or now.
  • Unsent draft preservation: reads the input box twice before closing; restores plain text (≤4,000 chars) unsent via bracketed paste on Claude; parks panes with queued messages or pasted images.
  • Same-service invariant: Claude only hands off to Claude, Codex only to Codex.

Zero-Trust Local Footprint

  • Credentials stay with Orca: never writes the Keychain, never copies subscription tokens, delegates account switches to orca account select.
  • Owner-only local storage: ~/.orca/oah/ is mode 0700, files mode 0600.
  • No shell interpolation: runs external CLIs via argument arrays only.
  • Zero npm dependencies: pure TypeScript running natively on Node.js.
Install

Two commands and an approval

  1. Install from GitHub. Orca prints the permissions and an approval fingerprint:

    orca plugin install ngoohebi/orca-auto-handoff

  2. Approve with the printed fingerprint:

    orca plugin install ngoohebi/orca-auto-handoff --approve ap1-…

  3. Open the OAH panel (gauge icon, right sidebar). Add a second account for a service in Orca if you haven't already — no other setup needed.

Optional: oah CLI (for scripts, automation, or headless servers)

You never need the CLI for everyday use in Orca. For terminal automation, headless orca serve hosts, or workspace pinning, the optional oah CLI talks to the same local background helper (~/.orca/oah/oahd.sock) with --json on every command:

oah status --json                # accounts, usage, runway, cooldowns & circuit state
oah active claude --json         # active account for scripts & external agents
oah use work@example.com         # select account + hand off on-screen session
oah pin <workspace> <account>    # pin a workspace/terminal out of auto-rotation
oah sync export > oah.json       # portable config backup
