Architecture

One daemon per host. CLI-first, quiet UI on top.

Every machine runs its own independent oahd daemon under ~/.orca/oah/. The oah CLI and the thin Orca plugin both speak the same NDJSON protocol — so terminal scripts, headless servers, and the desktop panel share one source of truth.

oahd Daemon ~/.orca/oah/

Owns state, config, burn-rate samples, direct quota checks, circuit breakers, and hand-off orchestration. Atomic 0600 JSON files, auto-started on demand.

oah CLI bin/oah

First-class CLI with --json on every command. Works locally, over SSH, or on headless orca serve hosts without needing the UI panel.

Quiet Orca Panel 3 tabs

Thin bridge with zero business logic. Connects to oahd.sock, provides native Claude agent.resume, and renders monochrome Accounts, History, and Settings tabs.

HTTP Proxy opt-in

Optional 127.0.0.1:4080 failover proxy (oah proxy start) for Anthropic & OpenAI API-key/relay endpoints with SSE streaming and oah bench.

Direct Live Quota

Current numbers for every saved account — even while you're away

Orca only polls the active account while you are using Orca. With Live quota on (the default), OAH fills missing or stale readings directly from each provider using the sign-in Orca already saved — never copying tokens or writing the Keychain.

Reliability & Controls

Built for long-running agent fleets

Quiet 3-Tab Panel

Monochrome Orca-native layout with hairline dividers, compact account rows (state beside name, Early hand off & End cooldown on the right), day-grouped History, Save/Undo settings, and ~1s tab-focus tracking. Early hand off keeps automatic hand-off ON.

3-State Circuit Breaker

Formal closed → open → half_open → closed state machine shared by subscription accounts and proxy providers. Healthy closed accounts always outrank recovering half_open ones.

Nested-Window Pacing & Model Policy

Combines 2-sample burn-rate runway with whole-window projection (usedPercent / elapsedFraction) and configurable model_window_policy (fallback-model, rotate, or ignore) for Fable/Opus weekly caps.

Per-Workspace Pinning

Run oah pin <workspace|terminal> <account> to lock dedicated sessions onto one account while the rest of your fleet rotates automatically.

Global Claude Status Line

One switch in Settings (on by default) covers every workspace on this computer, keeps any existing status line printing above OAH's account rows, and matches launcher config dirs (like ClaudeBar) automatically.

~1 ms Orca Socket + StopFailure Hook

Reads account & terminal lists over Orca's local socket in ~1 ms (no CLI spawn overhead), plus instant zero-regex Claude limit detection via oah event stop-failure.

Safety & Privacy

Fail-closed by default

Session Protection

  • Never interrupts a running turn: hands off only between turns, when idle, or at a limit.
  • On-screen care: ask (default), careful (presence-aware countdown), wait, or now.
  • Unsent draft preservation: reads the input box twice before closing; restores plain text (≤4,000 chars) unsent via bracketed paste on Claude; parks if queued messages or pasted images exist.
  • Same-service invariant: Claude only hands off to Claude, Codex only to Codex.

Zero-Trust Local Footprint

  • Credentials stay with Orca: never writes the Keychain, never copies subscription tokens, delegates account switches to orca account select.
  • Owner-only local storage: ~/.orca/oah/ is mode 0700, files mode 0600; oah sync export redacts API keys automatically.
  • No shell interpolation: runs external CLIs via argument arrays only.
  • Zero npm dependencies: pure TypeScript running natively on Node.js ≥ 22.18.
Install

CLI in 10 seconds, quiet Orca panel in two commands

  1. Run oah directly from a checkout (auto-starts oahd on demand):

    git clone https://github.com/ngoohebi/orca-auto-handoff.git
cd orca-auto-handoff
./bin/oah status

  2. Install the thin Orca plugin for instant event push, native Claude agent.resume, and the 3-tab sidebar panel:

    orca plugin install ngoohebi/orca-auto-handoff
# approve with the printed fingerprint:
orca plugin install ngoohebi/orca-auto-handoff --approve ap1-…

  3. Open the OAH panel in Orca's right sidebar, or control everything from any terminal with oah.
