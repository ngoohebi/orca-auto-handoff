Architecture

One daemon per host. One session per workspace.

Every machine runs its own independent oahd daemon under ~/.orca/oah/. The oah CLI and the thin Orca plugin both speak the same NDJSON protocol — eliminating multi-server routing complexity and keeping CLI, scripts, and GUI 100% in sync.

oahd Daemon ~/.orca/oah/

Owns state, config, burn-rate history, circuit breakers, and hand-off orchestration. Atomic 0600 JSON files, auto-started on demand.

oah CLI bin/oah

First-class CLI with --json on every command. Works locally, over SSH, or on headless orca serve hosts without needing the UI panel.

Thin Orca Plugin worker.ts

Zero business logic. Connects to oahd.sock, relays host events, exposes native Claude agent.resume, and renders the 4-tab OAH panel.

HTTP Proxy opt-in

Optional 127.0.0.1:4080 failover proxy for Anthropic & OpenAI API-key/relay endpoints with SSE streaming and latency benchmarking.

What's New in v0.5.0

Hardened by real-world fleet usage

Incorporates battle-tested reliability patterns from Orca's multi-account community (#20512) and local proxy HA workflows.

3-State Circuit Breaker

Formal closed → open → half_open → closed state machine shared by subscription accounts and proxy providers. Healthy closed accounts always outrank recovering half_open ones.

Codex ordinaryUsageAllowed Gate

Never fooled by the codex_bengalfox Spark bucket sitting at 0% when ordinary Codex quota is exhausted. Expired logins map cleanly to sign-in instead of looping.

Nested-Window Pacing

Computes whole-window projection (usedPercent / elapsedFraction, guarded at ≥5% elapsed) across 5h, weekly, and model windows alongside 2-sample burn-rate runway.

Model-Window Policy

Configure model_window_policy as fallback-model (try /model <next> first), rotate (proactively rotate on Fable/Opus weekly caps), or ignore.

Per-Workspace Pinning

Run oah pin <workspace|terminal> <account> to lock dedicated long-running sessions onto one account while the rest of your fleet rotates freely.

Instant StopFailure Hook + Live Probes

Zero-regex Claude limit detection via oah event stop-failure, plus fallback probes for codex app-server, free claude -p "/usage", and OpenCode Go.

Dual-Plane Failover

Subscription hand-offs + optional API-key HTTP proxy

Use Orca-managed subscription accounts for session hand-off/resume, or enable the opt-in local HTTP proxy for mid-turn zero-interruption failover across API-key relays — both managed from the same CLI and OAH Panel.

Safety & Privacy

Fail-closed by default

Session Protection

  • Never interrupts a running turn: hands off only between turns, when idle, or at a limit.
  • On-screen care: ask (default), careful (presence-aware countdown), wait, or now.
  • Unsent draft preservation: reads the input box twice before closing; restores plain text (≤4,000 chars) unsent via bracketed paste on Claude; parks if queued messages or pasted images exist.
  • Same-service invariant: Claude only hands off to Claude, Codex only to Codex.

Zero-Trust Local Footprint

  • Never touches subscription tokens or keychains: delegates all selection to orca account select.
  • Private owner-only storage: ~/.orca/oah/ is mode 0700, files mode 0600; oah sync export redacts API keys automatically.
  • No shell interpolation: runs orca and git via argument arrays only.
  • Zero npm dependencies: pure TypeScript running natively on Node.js ≥ 22.18.
Install

CLI in 10 seconds, thin Orca panel in two commands

  1. Run oah directly from a checkout (auto-starts oahd on demand):

    git clone https://github.com/ngoohebi/orca-auto-handoff.git
cd orca-auto-handoff
./bin/oah status

  2. Install the thin Orca plugin for instant event push, native Claude agent.resume, and the 4-tab sidebar panel:

    orca plugin install ngoohebi/orca-auto-handoff
# approve with the printed fingerprint:
orca plugin install ngoohebi/orca-auto-handoff --approve ap1-…

  3. Open the OAH panel in Orca's right sidebar, or control everything from any terminal with oah.
